## v1.0 — 公益站上线 (2026-07)

<Callout type="note" title="里程碑">

AI Rider 公益 AI API 平台正式上线。

### 首版功能

- 用户注册与令牌管理
- 兼容 OpenAI API 格式的调用入口
- 接入 OpenAI、Anthropic、DeepSeek、Qwen 等主流模型
- 在线操练场（Playground）
- 使用记录与额度查看
- 每日免费额度

### 已知限制

- 每日额度有限，先到先得
- 个人维护，不承诺服务可用性
- 模型列表可能动态调整
