## 这是什么

AI Rider 公益站是一个**面向 AI 学习者的免费 API 平台**。它不是一个商业产品，而是一位普通 AI 用户（我）为了帮助更多像我当初一样起步学习 AI 的人而搭建的。

<Callout type="info" title="说人话">
  我曾经也是一个对着 API 文档一头雾水的小白。我知道很多人想学 AI，但不想在试错阶段就花钱。这个站就是我收集的一些资源，帮大家低成本入门。
</Callout>

## 我的初心

我不是什么 AI 专家，也不是公司。我是一个和你一样的 AI 用户，在学习的路上受到很多开源社区和免费资源的帮助。现在我有能力做一些事来回馈：

- **收集资源**：把好用的、免费的 AI 接口整理出来
- **降低门槛**：让你不用注册一堆账号、绑信用卡就能体验大模型
- **一起进步**：希望能帮到像我当初一样迷茫的学习者
