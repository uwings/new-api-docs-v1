## 这是什么

aididai.cn 是一个面向中文用户的**公益 AI API 平台**，免费提供主流大语言模型的 API 调用服务。平台基于 New API 开源项目构建，兼容 OpenAI API 标准格式，让你无需自建基础设施即可接入 GPT、Claude、DeepSeek 等模型。

简单来说：你在这里注册账号、创建令牌、拿到一个 API Key，然后就能像调用 OpenAI 一样调用各种 AI 模型——但**不花钱**。

## 谁在维护

本站由个人开发者维护，以公益性质运营。服务器和 API 成本由维护者自行承担，平台不向用户收取任何费用。

<Callout type="info">
  本站不是商业服务，没有公司实体，没有客服团队。遇到问题请在社区反馈或发送邮件至 support@aididai.cn。
</Callout>

## 为什么免费

原因很简单：

1. **降低门槛**——很多人对 AI 感兴趣，但不想为试错付费。公益站让你免费体验真实 API 调用。
2. **学习用途**——适合写作业、做毕业设计、跑实验、搭个人项目，这些场景下付费 API 的成本不值得。
3. **社区回馈**——维护者从开源社区受益，以此方式回馈。

<Callout type="warn" title="免费 ≠ 无限">
  公益站有每日额度上限和速率限制。请合理使用，不要用于商业项目或大规模生产环境。
</Callout>

## 服务范围

平台提供以下服务：

- **文本对话**：GPT、Claude、DeepSeek、Qwen 等主流大语言模型
- **API 兼容**：完全兼容 OpenAI API 格式，现有代码只需改一行 Base URL 即可切换
- **在线操练场**：网页端直接对话测试，无需写代码
- **使用记录**：查看你的调用历史和额度消耗

平台**不提供**：

- 图像生成、语音合成、视频生成等多媒体服务（除非另行说明）
- SLA 或可用性承诺
- 商业级技术支持

## 适合谁

| 用户类型 | 适合程度 | 典型场景 |
|---------|---------|---------|
| AI 初学者 | ⭐⭐⭐⭐⭐ | 第一次接触 API，想体验大模型 |
| 学生 | ⭐⭐⭐⭐⭐ | 课程作业、毕业设计、论文实验 |

## 不适合谁

- 需要高可用性保障的线上业务
- 有大规模并发需求的生产环境
- 对数据隐私有严格合规要求的企业场景
- 需要专属技术支持的商业用户

这些场景请选择 OpenAI、硅基流动、阿里云等付费平台——它们提供 SLA、更高限额和商业支持。
