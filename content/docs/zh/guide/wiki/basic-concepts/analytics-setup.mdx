## 关于可用性

aididai.cn 是公益性质的平台，**不承诺 99.99% 或任何级别的服务可用性**。

<Callout type="warn" title="重要提醒">
  本站由个人维护，服务器和上游 API 均可能出现计划外中断。如果你的项目对可用性有要求，请不要依赖本站作为唯一 API 来源。
</Callout>

可能影响可用性的因素：

| 因素 | 说明 | 你能做的 |
|------|------|---------|
| 服务器维护 | 维护者需要更新、重启服务 | 避开维护时段使用 |
| 上游服务商中断 | OpenAI、Anthropic 等自身故障 | 切换到其他可用模型 |
| 额度耗尽 | 平台每日免费额度有限 | 上午调用，避免高峰 |
| 网络波动 | 服务器或上游的网络抖动 | 重试请求 |
| 不可抗力 | 服务器故障、域名/网络问题 | 等待恢复或使用备用方案 |

## 维护安排

平台可能不定期进行维护操作，包括但不限于：

- 更新平台版本
- 添加或下线模型
- 修复已知问题
- 调整额度策略

<Callout type="info">
  维护前会尽量通过公告或邮件通知用户，但不保证提前通知所有变更。
</Callout>

## 如何了解服务状态

如果遇到 API 调用异常，请按以下步骤排查：

<Steps>
  <Step title="检查额度">
    登录控制台，确认你的每日剩余额度是否充足。
    额度耗尽是最常见的调用失败原因。
  </Step>
  <Step title="检查模型是否可用">
    调用 `GET /v1/models` 查看当前可用模型列表。
    某些模型可能已下线。
  </Step>
  <Step title="查看错误信息">
    API 返回的 JSON 错误信息中包含具体原因，
    例如 `rate_limit_exceeded`、`insufficient_quota` 等。
  </Step>
  <Step title="等待并重试">
    如果是临时性问题（网络波动、上游瞬时故障），
    等待几分钟后再试通常可以解决。
  </Step>
  <Step title="联系反馈">
    如果问题持续存在且不属于已知限制，
    请发送邮件至 uwings@gmail.com 描述问题。
  </Step>
</Steps>

## 关于数据持久性

<Callout type="error" title="不保证数据安全">
  公益站不保证用户数据的持久性和安全性。请不要在 API 请求中包含敏感个人信息、商业机密或重要数据。平台可能在任何时候重置数据库或下线服务。
</Callout>

你需要注意：

- **调用记录**：仅保留近期数据，不保证长期存储
- **令牌安全**：妥善保管你的 API Key，泄露后请立即删除并重建
- **重要对话**：如果对话内容有价值，请自行保存，不要依赖平台

## 长期规划

公益站没有明确的长期运营承诺。维护者会尽力持续运营，但以下情况可能导致服务终止：

- 成本无法承担
- 时间精力不足
- 政策或法律原因

建议始终保留迁移到付费平台的能力，将本站视为临时、辅助性质的资源。
