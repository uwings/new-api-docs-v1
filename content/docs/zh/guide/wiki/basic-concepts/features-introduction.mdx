## 免费额度

注册即送每日免费额度，可用于调用平台支持的模型。额度每日重置，未使用部分不累积。

<Callout type="info" title="额度说明">
  免费额度基于 Token 计费模型。不同模型的消耗比例不同，通常 GPT-4 系列比 GPT-3.5 消耗更快。
  具体额度上限可能根据平台运营情况动态调整。
</Callout>

## 支持的模型

平台接入主流 AI 服务提供商，支持以下类型的模型：

### 文本对话模型

- **OpenAI**：GPT-4o、GPT-4o-mini、GPT-5 系列等
- **Anthropic**：Claude 3.5 Sonnet、Claude 3 Opus 等系列
- **国产模型**：DeepSeek、Qwen（通义千问）、GLM 等
- **其他**：根据接入情况动态更新

具体可用模型列表请在[操练场](#在线操练场)页面或 API `/v1/models` 接口查看。

<Callout type="warn">
  模型可用性取决于上游服务商状态。某些模型可能因成本或策略原因临时下线，恕不另行通知。
</Callout>

## OpenAI API 兼容格式

平台完全兼容 OpenAI API 调用格式，你现有的 OpenAI 客户端代码只需修改两处即可使用：

<Steps>
  <Step title="修改 Base URL">
    将 API 地址从 `https://api.openai.com` 改为 `https://airider.cn`
  </Step>
  <Step title="替换 API Key">
    使用你在本站创建的令牌替换 OpenAI 的 API Key
  </Step>
</Steps>

支持的接口端点：

- `POST /v1/chat/completions` — 对话补全
- `POST /v1/completions` — 文本补全
- `GET /v1/models` — 模型列表
- `POST /v1/embeddings` — 文本向量化（视模型支持情况）

## 在线操练场

不想写代码？平台提供网页端操练场（Playground），直接在浏览器中与 AI 模型对话：

- 选择模型、调整参数（temperature、max_tokens 等）
- 实时查看输出结果
- 支持流式输出和非流式模式
- 一键复制调用代码

适合快速测试 Prompt 效果，或验证模型行为。

## 使用记录

平台记录你的每次 API 调用，你可以在控制台查看：

- 调用时间与模型
- Token 消耗与费用折算
- 调用状态（成功/失败）
- 剩余额度

<Callout type="info">
  使用记录仅保留最近一段时间的数据，具体保留期限取决于平台存储策略。
</Callout>

## 令牌管理

你可以创建多个 API 令牌（Token），用于不同项目或场景：

- 为每个令牌设置名称，便于区分用途
- 随时禁用或删除不再使用的令牌
- 指定每个令牌可访问的模型范围

## 其他功能

| 功能 | 说明 |
|------|------|
| 流式输出 | 支持 SSE 流式响应，逐 token 返回 |
| 多轮对话 | 支持 messages 数组实现上下文对话 |
| Function Calling | 支持 OpenAI 函数调用格式（视模型支持） |
| 思考模式 | 部分推理模型支持 reasoning effort 设置 |
