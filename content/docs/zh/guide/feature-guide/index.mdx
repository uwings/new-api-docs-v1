## 管理员功能

如果你部署了自己的 New API 实例，以下是对应的管理文档（需 Root/Admin 权限）：

- [渠道管理](/zh/docs/guide/feature-guide/admin/channel) — 配置上游 AI 服务商
- [用户管理](/zh/docs/guide/feature-guide/admin/user) — 管理注册用户
- [系统设置](/zh/docs/guide/feature-guide/admin/system-setting) — 全局配置（Root 专属）
- [高级配置](/zh/docs/guide/feature-guide/admin/system-setting-advanced) — 倍率、限流、支付等

> 公益站由平台管理员统一维护，普通用户无需关心管理功能。
