令牌（Token）是调用公益站 API 的凭证。你需要先创建一个令牌，才能在代码或客户端中使用公益站 API。

## 准备工作

- 已注册公益站账号并登录
- 打开控制台：访问 [控制台地址](#) 或点击页面顶部「控制台」链接

## 创建第一个令牌

### 第 1 步：进入令牌管理页

登录控制台后，在左侧导航点击「令牌」，或直接访问 `/console/token`。

![令牌列表页](/assets/guide/feature-guide/token-list.png)

### 第 2 步：点击「创建令牌」

在令牌列表页右上角点击「创建令牌」按钮，弹出创建弹窗。

![创建令牌弹窗](/assets/guide/feature-guide/token-create.png)

### 第 3 步：填写令牌名称

为令牌起一个便于识别的名字，例如「我的测试令牌」。

### 第 4 步：配置选项（可选）

| 配置项 | 说明 | 建议 |
|--------|------|------|
| 过期时间 | 令牌有效期，留空表示永不过期 | 首次使用可留空 |
| 剩余配额 | 限制该令牌可消耗的最大额度 | 按需设置 |
| 模型限制 | 限定只能调用指定模型 | 留空表示不限制 |
| IP 白名单 | 限定来源 IP | 留空表示不限制 |

<Callout type="info">
  首次创建令牌，高级配置选项全部留空即可，直接点击「提交」。
</Callout>

### 第 5 步：复制保存令牌 Key

点击「提交」后，弹窗会显示完整的令牌 Key（以 `sk-` 开头）。

**立即复制保存！** 关闭弹窗后无法再次查看完整 Key。

![令牌创建成功，显示完整 Key](/assets/guide/feature-guide/token-created-key.png)

<Callout type="warn">
  ⚠️ 令牌 Key 仅在创建时完整显示一次。请立即复制保存到安全的地方。令牌 Key 等同于你的 API 密码，请勿泄露给他人或提交到代码仓库。
</Callout>

## 验证令牌

创建令牌后，用以下命令验证是否可用：

```bash
curl https://your-api-endpoint/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌Key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"hello"}]}'
```

如果返回正常的 JSON 响应，说明令牌可用。遇到 401/403/429？→ [常见错误速查](/zh/docs/public/getting-started/common-errors)

## 管理令牌

- **编辑令牌**：在令牌列表中点击「编辑」，可修改配置（不能修改 Key 本身）
- **删除令牌**：点击「删除」，令牌立即失效，无法恢复
