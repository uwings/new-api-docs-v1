公益站提供免费的 AI API 额度，供学习和体验使用。本文说明额度分配规则和配额计算方式。

## 免费额度

公益站为每位注册用户提供免费额度：

- **额度来源**：由站方统一采购并分配，无需付费
- **额度数量**：可能根据资源情况动态调整，不保证固定数值
- **额度有效期**：以控制台显示为准

<Callout type="info">
  公益站资源有限，额度可能随运营情况调整。建议合理使用，避免浪费。
</Callout>

## 配额计算

API 调用按 Token 消耗配额：

### 什么是 Token

Token 是大语言模型处理文本的基本单位。大致换算关系：

| 语言 | 1 个 Token ≈ |
|------|-------------|
| 英文 | 0.75 个单词 |
| 中文 | 0.5-1 个汉字 |

### 消耗公式

```
实际消耗 = Token 数量 ÷ 1000 × 模型倍率
```

不同模型的倍率不同，通常：
- 小型模型（如 gpt-4o-mini）：倍率低，消耗少
- 大型模型（如 gpt-4o）：倍率高，消耗多
- 输入和输出分别计费

### 查看余额

登录控制台，在仪表盘或令牌管理页可查看：
- 已用配额
- 剩余配额
- 各模型消耗明细

## 限流规则

| 维度 | 说明 |
|------|------|
| 每分钟请求数 (RPM) | 防止单用户高频请求影响他人 |
| 每分钟 Token 数 (TPM) | 限制单次大量 Token 消耗 |
| 每日请求数 (RPD) | 部分模型可能有日调用上限 |

<Callout type="warn">
  超出限流会返回 `429 Too Many Requests`。请等待后重试，不要连续重试。详见 [常见错误速查](/zh/docs/public/getting-started/common-errors)。
</Callout>

## 额度用完了怎么办

- 公益站额度用尽后，需等待站方补充或联系管理员
- 如需更大用量，建议使用付费 API 服务
- 禁止通过批量注册账号绕过额度限制

## 为什么免费

公益站的算力资源来自站方采购和社区赞助。目标是降低 AI 学习和体验的门槛，不是替代商业 API 服务。你的合理使用是对公益资源最大的尊重。
