title: 问题反馈
---

欢迎反馈文档问题或功能建议。

## 📧 反馈渠道

- **文档内容问题**（错别字、错误、过时内容）：邮件 uwings@gmail.com
- **API 使用问题**：查看 [常见错误速查](/zh/docs/public/getting-started/common-errors) 和 [FAQ](/zh/docs/support/faq)
- **功能建议**：欢迎来 [社区论坛](https://BBS.UXlib.CN) 讨论

## 📝 反馈内容建议

为了让我们更快定位和解决问题，建议在反馈中包含以下信息：

- 具体哪个页面 / 哪段内容有问题
- 期望的正确内容是什么
- 如果方便，附上截图

<Callout type="info" title="提示">
  公益站由个人维护，反馈处理可能需要一些时间，感谢理解。如果是 API 服务异常，请先查看控制台公告。
</Callout>
