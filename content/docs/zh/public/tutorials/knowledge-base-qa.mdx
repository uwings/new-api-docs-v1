RAG（Retrieval-Augmented Generation）是目前最实用的 AI 应用模式：**先搜索相关资料，再让 AI 基于资料回答**。

## 为什么需要 RAG

大模型有两个天生缺陷：
- 训练数据有截止日期，不知道新信息
- 会编造不存在的事实（幻觉）

RAG 的解决思路：不让模型凭记忆回答，而是**先把相关文档找出来，让模型"照着念"**。

```
用户提问："公司年假政策是什么？"
         ↓
    搜索公司文档库
         ↓
    找到：年假政策.pdf 第3页
         ↓
    发给 AI："根据以下文档回答问题：\n[文档内容]\n\n问题：公司年假政策？"
         ↓
    AI 回答："根据公司政策，入职满1年享有5天年假..."
```

## 三步搭建

### 第一步：准备文档

```python
# 把文档切成小块（chunks）
documents = [
    "公司年假政策：入职满1年享有5天带薪年假，此后每满1年增加1天...",
    "加班调休规则：工作日加班可申请1:1调休，周末加班1:1.5...",
    "报销流程：在OA系统提交报销申请，附发票照片，审批流程为..."
]
```

### 第二步：向量化存储

```python
import requests
import numpy as np

def get_embedding(text):
    """把文字转成向量"""
    resp = requests.post(
        "https://api.unsnow.org/v1/embeddings",
        headers={"Authorization": "Bearer sk-你的令牌"},
        json={"model": "text-embedding-3-small", "input": text}
    )
    return resp.json()["data"][0]["embedding"]

# 为每个文档生成向量
vectors = [get_embedding(doc) for doc in documents]
```

### 第三步：检索 + 问答

```python
from numpy import dot
from numpy.linalg import norm

def cosine_similarity(a, b):
    return dot(a, b) / (norm(a) * norm(b))

def ask(question):
    # 1. 把问题转成向量
    q_vector = get_embedding(question)

    # 2. 找最相关的文档
    scores = [cosine_similarity(q_vector, v) for v in vectors]
    best_idx = scores.index(max(scores))
    context = documents[best_idx]

    # 3. 让 AI 基于文档回答
    resp = requests.post(
        "https://api.unsnow.org/v1/chat/completions",
        headers={"Authorization": "Bearer sk-你的令牌"},
        json={
            "model": "gpt-3.5-turbo",
            "messages": [
                {"role": "system", "content": f"根据以下文档回答问题。如果文档中没有相关信息，就说不知道。\n\n文档：{context}"},
                {"role": "user", "content": question}
            ]
        }
    )
    return resp.json()["choices"][0]["message"]["content"]

# 测试
print(ask("我有几天年假？"))
```

## 进阶：用向量数据库

当文档量增大时，用专门的向量数据库替代数组：

| 方案 | 适合场景 |
|------|---------|
| SQLite + sqlite-vec | 1000 条以内，单机 |
| ChromaDB | 1万-10万条，单机 |
| Qdrant | 10万+，生产环境 |
| Milvus | 百万级，分布式 |

Cherry Studio 内置了知识库功能，不需要写代码也能体验 RAG → [配置 Cherry Studio](cherry-studio.mdx)

## 常见陷阱

- **文档切得太小** → 上下文不完整，回答不准。建议每块 200-500 字
- **只取一条** → 改为取 top 3-5 条文档，AI 综合判断
- **不提"不知道"** → System Prompt 要明确告诉 AI 不编造
