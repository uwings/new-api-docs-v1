## 前置条件

- 已创建 API 令牌
- macOS/Linux 自带 curl，Windows 用户需安装（或用 WSL）

## Hello World

打开终端，把 `sk-你的令牌` 替换后粘贴：

```bash
curl https://api.unsnow.org/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的令牌" \
  -d '{"model":"gpt-3.5-turbo","messages":[{"role":"user","content":"你好"}]}'
```

## 实用示例

### 翻译

```bash
curl https://api.unsnow.org/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的令牌" \
  -d '{
    "model": "gpt-3.5-turbo",
    "messages": [
      {"role": "system", "content": "你是翻译，只输出翻译结果。英文译成中文，中文译成英文。"},
      {"role": "user", "content": "Artificial intelligence is transforming every industry."}
    ]
  }'
```

### 代码审查

```bash
curl https://api.unsnow.org/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的令牌" \
  -d '{
    "model": "deepseek-chat",
    "messages": [
      {"role": "system", "content": "你是代码审查员。指出 bug、安全问题和改进建议。用中文回答。"},
      {"role": "user", "content": "审查这段代码：\n\ndef divide(a, b):\n    return a / b\n\nresult = divide(10, 0)\nprint(result)"}
    ]
  }'
```

### 多轮对话

带上之前的消息历史，模型能记住上下文：

```bash
curl https://api.unsnow.org/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的令牌" \
  -d '{
    "model": "gpt-3.5-turbo",
    "messages": [
      {"role": "user", "content": "我叫小明，今年25岁"},
      {"role": "assistant", "content": "你好小明！25岁正是好年纪。"},
      {"role": "user", "content": "我刚才说我叫什么？"}
    ]
  }'
```

## 流式输出

加 `"stream": true` 让回复逐字出现：

```bash
curl https://api.unsnow.org/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的令牌" \
  -d '{"model":"gpt-3.5-turbo","stream":true,"messages":[{"role":"user","content":"讲个笑话"}]}'
```

## 常见问题

- **401** → 检查 `Bearer` 后面有没有空格、令牌是否完整
- **502/503** → 上游模型繁忙，换个模型或等几秒
- **Content-Type 错误** → 确认 `-H "Content-Type: application/json"`
