title: 工具与客户端

不只是用 curl 写代码。这些客户端让你不写一行代码就能用公益站 API。

## 对话客户端

桌面应用，装完就能聊天。

| 工具 | 适合 | 费用 | 特点 |
|------|------|------|------|
| [Cherry Studio](cherry-studio.mdx) | 所有人 | 免费开源 | 界面好看，中文友好，插件丰富 |
| [DeepChat](deepchat.mdx) | 日常使用 | 免费 | 轻量简洁，启动快 |
| [AionUI](aion-ui.mdx) | 开发者 | 免费 | 多模型对比，Prompt 管理 |

## 编程工具

让 AI 直接帮你写代码。

| 工具 | 适合 | 费用 | 特点 |
|------|------|------|------|
| [Claude Code](claude-code.mdx) | 专业开发者 | 免费 + API费 | 终端内的 AI 编程搭档 |
| [Codex CLI](codex-cli.mdx) | 开发者 | 免费 + API费 | OpenAI 官方 CLI 工具 |
| [CC Switch](cc-switch.mdx) | Claude Code 用户 | 免费 | 管理多个 Code 配置 |

## Agent 与自动化

不止聊天，AI 能帮你干活。

| 工具 | 适合 | 费用 | 特点 |

| [OpenClaw](openclaw.mdx) | 重度 AI 用户 | 免费开源 | 多平台消息接入 |

## 按场景选择

| 你想做什么 | 推荐工具 |
|-----------|---------|
| 聊天体验 AI | Cherry Studio |
| 写代码、改 Bug | Claude Code + 公益站 API |
| 做个 QQ/微信机器人 | LangBot |
| 批量翻译、分析文本 | Python 脚本 + 公益站 API |
| 搭建知识库问答 | Cherry Studio 知识库 + RAG |

每个工具的详细配置和接入方法请点击对应页面。
