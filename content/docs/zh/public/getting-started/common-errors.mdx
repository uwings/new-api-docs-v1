---
title: 常见错误速查
---

调用 API 时遇到错误？下面是常见错误码和解决方案。

## 401 Unauthorized

**含义**：未授权，令牌（API Key）错误或缺失。

**常见原因**：
- 没有在请求头中设置 `Authorization`
- 令牌写错了（多一个空格、少一个字符）
- 令牌已过期或已被删除

**检查方法**：

```bash
# 确认请求头中 Authorization 格式正确
-H "Authorization: Bearer sk-你的令牌"
```

**解决**：
1. 检查令牌是否完整复制（从 `sk-` 开始）
2. 登录控制台 → 令牌 → 确认令牌状态
3. 如已删除，创建新令牌

## 403 Forbidden

**含义**：无权访问该模型或资源。

**常见原因**：
- 请求的模型不在你的令牌权限范围内
- 该模型暂停了免费服务

**解决**：
1. 在控制台检查令牌的模型访问权限
2. 换一个可用的模型试试

## 404 Not Found

**含义**：请求的模型不存在。

**常见原因**：模型名称拼写错误。

```bash
# 错误示例
"model": "gtp-3.5-turbo"    # 写成了 gtp

# 正确
"model": "gpt-3.5-turbo"    # 正确的拼写
```

**解决**：检查 [选择模型](/zh/docs/public/getting-started/choose-model) 页面确认正确的模型名称。

## 429 Too Many Requests

**含义**：请求太频繁，触发了频率限制。

**解决**：
1. 等待几秒后重试
2. 如果已用完当天额度，等次日 0 点重置
3. 检查是否有程序在循环调用 API（忘记加延时）

## 500 Internal Server Error

**含义**：服务端内部错误。

**解决**：
1. 等待几秒钟重试
2. 如果持续报错，换一个模型试试
3. 查看 [服务状态页](#) 确认是否有服务中断

## 503 Service Unavailable

**含义**：上游模型提供商暂时不可用。

**解决**：换一个模型重试。例如从 `gpt-3.5-turbo` 换成 `deepseek-chat`。

## 连接超时

**含义**：请求长时间未收到响应。

**排查思路**：

```bash
# 1. 确认网络能连通
curl -v https://airider.cn/

# 2. 检查是否有代理/防火墙拦截

# 3. 增加超时时间
curl --connect-timeout 30 --max-time 120 ...
```

**解决**：
1. 检查网络连接
2. 关闭代理试试
3. 换一个网络环境（如手机热点）
4. 如果持续超时，可能是服务器维护中

## 仍需帮助？

如果以上方法无法解决你的问题，可以：
- 查看 [服务状态页](#) 确认是否大面积故障
- 在控制台提交反馈
- 加入社区群组寻求帮助
