## 这是什么

公益 AI 文档站是一个**完全免费**的 AI API 服务。我们通过社区支持和上游赞助，向所有人提供免费的大模型调用接口，无需绑定信用卡，无需付费升级。

## 核心特点

- **完全免费**：无隐藏费用，无自动扣费
- **OpenAI 兼容**：使用标准 OpenAI API 格式，所有兼容客户端都能直接接入
- **多模型支持**：涵盖文本对话、代码生成、图像理解等多种模型
- **无需审核**：注册即用，创建令牌即可开始调用

## 适合谁用

| 用户类型 | 典型场景 |
|---------|---------|
| AI 初学者 | 体验大模型对话、学习 AI 开发 |
| 开发者 | 快速原型验证、API 调用测试 |
| 学生/研究者 | 课程学习、论文实验 |
| 个人项目 | 业余项目、小工具开发 |

## 不适合什么

- **生产级商用服务**：本站不承诺 SLA（服务水平协议），免费额度有限且可能调整
- **高并发大型应用**：免费服务有速率限制，不适合高 QPS 场景
- **处理敏感数据**：数据会经由上游模型提供商处理，请注意隐私保护
