## 使用规则

使用公益站 API 即表示你同意以下规则。

### 允许的行为

- 个人学习、研究、项目开发
- 非商业用途的 AI 应用开发和测试
- 使用兼容客户端（Cherry Studio、Claude Code 等）接入
- 合理频率的 API 调用

### 禁止的行为

以下行为将导致账号被封禁：

- **违法内容**：生成或传播违法、违规内容
- **滥用服务**：恶意刷接口、绕过限流、伪造请求
- **商业转售**：将免费 API 用于商业服务并收费
- **侵犯他人权益**：生成侵权、诽谤、骚扰内容
- **安全攻击**：对服务进行安全扫描、DDoS 攻击

### 处置措施

违规行为的处理梯度：

1. **警告**：首次轻微违规，系统发出警告
2. **限流**：降低调用频率
3. **临时封禁**：暂停 API 访问 7-30 天
4. **永久封禁**：严重违规或屡次违规

如果认为封禁有误，可以通过控制台提交申诉，我们会在 3 个工作日内回复。

## 隐私提醒

### 我们收集什么

| 数据 | 用途 | 保存时间 |
|------|------|---------|
| 用户名/邮箱 | 账号管理、找回密码 | 账号存续期间 |
| API 调用日志（调用量） | 额度统计、防滥用 | 30 天 |
| 异常访问日志 | 安全排障 | 7 天 |

### 我们不做什么

- **不存储** 你的对话内容和 API 请求体
- **不分享** 你的个人信息给第三方
- **不查看** 你的具体对话内容（除非安全排查需要）

### 上游模型提供商

当你调用 API 时，你的请求会传送给对应模型的上游提供商（如 OpenAI、DeepSeek）。不同提供商有不同的隐私政策：

- [OpenAI 隐私政策](https://openai.com/policies/privacy-policy)
- [DeepSeek 隐私政策](https://deepseek.com/policy)

> ⚠️ **注意**：不要在对话中发送密码、身份证号、银行卡号等敏感信息。
