## 可用模型

公益站提供多种模型，覆盖不同场景。以下列表会随上游供应情况动态更新。

### 对话与文本生成

| 模型名称 | 适用场景 | 特点 |
|---------|---------|------|
| `gpt-3.5-turbo` | 日常对话、简单任务 | 快速、低成本 |
| `gpt-4` | 复杂推理、长文写作 | 高质量、支持更长上下文 |
| `gpt-4o` | 多模态对话 | 支持文本+图像输入 |

### 推理与代码

| 模型名称 | 适用场景 | 特点 |
|---------|---------|------|
| `deepseek-chat` | 代码生成、技术讨论 | 编程能力强 |
| `deepseek-reasoner` | 复杂推理、数学 | 深度思考 |

### 图像理解

| 模型名称 | 适用场景 | 特点 |
|---------|---------|------|
| `gpt-4o` | 图片内容分析 | 支持多图同时输入 |
| `gemini-2.5-flash` | 图片/文档识别 | 响应快 |

## 如何选模型

**一般对话、翻译、简单问答** → 选 `gpt-3.5-turbo`，够用且不浪费额度

**写长文、复杂分析、编程** → 选 `deepseek-chat` 或 `gpt-4`

**涉及图片理解** → 选 `gpt-4o`

**不确定选哪个** → 先用 `gpt-3.5-turbo` 试试，效果不够再换

## 指定模型

在 API 请求中通过 `model` 参数指定：

```bash
curl https://api.unsnow.org/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -d '{"model": "deepseek-chat", "messages": [...]}'
```

完整模型列表和参数说明见 [开发参考 - AI 模型 API](/zh/docs/api/ai-model)。

## 模型状态说明

- **可用**：正常提供服务
- **繁忙**：请求量大，响应可能变慢
- **维护中**：上游暂时不可用，请换其他模型

可以在控制台或 [服务状态页](#) 查看实时模型状态。
