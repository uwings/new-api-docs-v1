## 注册

访问公益站控制台：[http://192.168.5.33:8500](http://192.168.5.33:8500)

1. 点击右上角 **「注册」** 按钮
2. 填写用户名、邮箱和密码
3. 点击 **「注册」** 完成

> **注意**：邮箱仅用于账号找回，不会发送垃圾邮件。建议使用真实邮箱以防账号丢失。

## 登录

1. 访问控制台
2. 输入用户名/邮箱和密码
3. 点击 **「登录」**

## 登录后

登录成功后你会看到控制台首页，在这里可以：

- 查看你的 **API 令牌**（Token / API Key）
- 查看 **使用额度** 和调用量统计
- 浏览 **可用模型** 列表
- 查看 **服务公告** 和状态
