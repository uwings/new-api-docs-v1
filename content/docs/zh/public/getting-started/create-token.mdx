## 什么是 API 令牌

API 令牌（Token/API Key）是一串字符，用作调用 API 时的身份凭证。**务必妥善保管，不要泄露给他人。**

## 创建令牌

1. 登录控制台
2. 进入左侧菜单 **「令牌」**
3. 点击 **「新建令牌」**
4. 设置令牌名称（方便自己识别即可，如 `我的第一个Key`）
5. 选择模型访问权限（默认全部可用模型）
6. 设置过期时间（可选，建议先设置为较长周期方便使用）
7. 点击 **「提交」**

创建成功后，**立即复制并保存令牌**。页面关闭后将无法再次查看完整的 Key 文本。

> ⚠️ 令牌仅显示一次，请立即复制并妥善保存。如果丢失，只能重新创建。

## 令牌格式

公益站令牌格式为 `sk-` 开头的一串字符，示例：

```
sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## 安全提醒

- **不要把令牌写在公开代码中**（尤其是 GitHub 公开仓库）
- **不要在截图中暴露令牌**
- 如果怀疑泄漏，在控制台中立即删除并创建新令牌
- 每个令牌可以独立设置权限和额度，建议不同用途使用不同令牌
