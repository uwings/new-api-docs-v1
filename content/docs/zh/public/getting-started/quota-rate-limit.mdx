---

## 免费额度

公益站目前提供以下免费额度（每用户/每天）：

| 项目 | 限额 | 说明 |
|------|------|------|
| 请求次数 | 200次/天 | 所有模型共享 |
| 每分钟请求 | 10次/分钟 | 防止滥用 |
| Token 总量 | 约50万 token/天 | 长对话消耗更多 |

> **重要说明**：免费额度会根据服务器负载和上游成本动态调整，不构成 SLA 承诺。我们会在控制台公告中提前通知额度变更。

## 限流说明

超过限额后，API 会返回以下错误：

| HTTP 状态码 | 含义 | 解决方法 |
|------------|------|---------|
| `429 Too Many Requests` | 请求太频繁或已超配额 | 等待几秒后重试，或等次日额度重置 |
| `503 Service Unavailable` | 上游模型繁忙 | 换一个模型重试 |

## 服务稳定性

公益站由社区和个人维护，依靠上游 API 赞助提供免费服务：

- **尽力稳定，但不承诺 SLA**：我们无法保证 7×24 小时 100% 可用
- **上游模型可能波动**：某个模型不可用时，请尝试切换到其他模型
- **维护会提前公告**：计划维护会在控制台公告中提前通知

## 数据流向

你的请求数据经过以下路径：

```
你的客户端 → 公益站服务器 → 上游模型提供商（如 OpenAI、DeepSeek 等）
                     ↓
                  不持久化存储
```

- 公益站**不存储**你的对话内容
- 上游模型提供商（如 OpenAI、DeepSeek）可能有自己的数据处理政策
- 各上游提供商的隐私政策请查看对应官网

## 如果额度不够用

目前免费额度覆盖个人学习和轻度使用。如果需要更高的调用量：

1. 检查是否可以优化调用方式（如减少重复请求、使用更小的模型）
2. 关注控制台公告了解额度调整计划
3. 考虑注册商业 API 提供商（如直接注册 OpenAI、DeepSeek）获取更高额度
