大模型不只是聊天。这篇文章介绍 AI API 能处理的几种数据类型。

## 文本（Text）

最基础的能力——输入文字，输出文字。

```bash
# 对话、翻译、写代码、改文章、总结、扩写...
{"role": "user", "content": "用 Python 写一个快速排序函数"}
```

## 图像（Image）

有些模型（如 gpt-4o、gemini-2.5-flash）支持**图片输入**——上传图片让 AI 理解图片内容。

```json
{
  "model": "gpt-4o",
  "messages": [{
    "role": "user",
    "content": [
      {"type": "text", "text": "这张图片里有什么？"},
      {"type": "image_url", "image_url": {"url": "https://example.com/photo.jpg"}}
    ]
  }]
}
```

能做什么：
- 识别图片中的物体和文字
- 读取截图中的内容（界面、表格、代码）
- 描述图片场景
- 理解图表和数据

**不能做什么**：
- 不能精准数数（"图里有几个人"可能数错）
- 不能做 OCR 精度高的文档识别（建议用专门的 OCR 工具）
- 图片分辨率越高 token 消耗越大

## 音频（Audio）

语音类模型可以将**语音转文字**（STT / Speech-to-Text）。

```bash
# Whisper 模型把音频转为文字
curl https://api.unsnow.org/v1/audio/transcriptions \
  -H "Authorization: Bearer sk-你的令牌" \
  -F file="@录音.mp3" \
  -F model="whisper-1"
```

支持格式：mp3、wav、m4a、ogg 等常见音频格式。

## Embedding（向量嵌入）

Embedding 是把**任意文字转换成一串数字（向量）**，用来做语义搜索。

"苹果很好吃" → `[0.12, -0.34, 0.87, ...]`  （1024 或 1536 个数字）
"这个水果不错" → `[0.11, -0.33, 0.88, ...]`  （与前一句很相似）
"今天天气真好" → `[-0.45, 0.78, -0.21, ...]`  （与前两句差异大）

相似的文字会有相似的数字向量。通过比较向量之间的"距离"，可以找到语义相近的内容。

**应用场景**：
- 文档搜索：输入自然语言查询，找到最相关的文档段落
- 相似内容推荐：找到和你正在看的内容相近的文章
- 知识库问答（RAG）：用 Embedding 检索相关资料，再发给 AI 回答

## 多模态组合

更高级的应用会组合多种模型：

```
用户上传一张图表截图 → gpt-4o 读取数据 → 发给 LLM 分析趋势 → 生成分析报告
语音查询 → Whisper 转文字 → LLM 理解意图 → 向量搜索知识库 → 生成回答
```
