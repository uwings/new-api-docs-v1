title: System Prompt、Temperature、流式输出
---

调 API 时，除了"我问你答"，还有几个参数可以控制 AI 的回答方式。

## System Prompt（系统提示）

System Prompt 是在**用户消息之前**发给模型的"角色设定"。

```json
{
  "model": "gpt-3.5-turbo",
  "messages": [
    {"role": "system", "content": "你是一个毒舌的代码审查员，用一句中文吐槽代码问题"},
    {"role": "user", "content": "for i in range(len(arr)): print(arr[i])"}
  ]
}
```

模型会以"毒舌代码审查员"的身份来回答，而不是默认的通用助手。

**实战用法**：

| 场景 | System Prompt 示例 |
|------|-------------------|
| 设定输出格式 | "只用 JSON 格式回复，不要其他内容" |
| 限定角色 | "你是翻译，只翻译为中/英文，不做解释" |
| 控制风格 | "用小学生能听懂的话解释" |
| 编程辅助 | "只输出代码，不需要解释" |

> System Prompt 也消耗 token，所以要精简——说清楚要什么，而不是写一篇长文。

## Temperature（温度）

Temperature 控制输出的**随机性**，范围 0-2。

- **0** — 完全确定，同样输入永远同样输出。适合代码生成、数学计算
- **0.7** — 默认值，平衡创意和准确性
- **1.5+** — 放飞自我，输出天马行空。适合头脑风暴、写诗

```bash
# 写代码 → 用低温度
-d '{"model": "gpt-3.5-turbo", "temperature": 0.2, "messages": [...]}'

# 写故事 → 用高温度
-d '{"model": "gpt-3.5-turbo", "temperature": 1.2, "messages": [...]}'
```

## Stream（流式输出）

默认情况下，API 会等整个回答生成完才一次性返回。开启流式输出后，模型**生出一段就立刻发过来一段**。

```bash
-d '{"model": "gpt-3.5-turbo", "stream": true, "messages": [...]}'
```

流式输出的效果就像 ChatGPT 那种"一个字一个字往外蹦"的体验。

**什么时候用**：
- 做聊天界面 → 开启流式，用户体验好
- 做后台批处理 → 关闭流式，数据更规整好处理

## 其他常用参数

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `max_tokens` | 限制输出最大长度 | 无限制 |
| `top_p` | 另一种随机性控制（与 temperature 选一个用） | 1 |
| `stop` | 遇到指定词就停止生成 | 无 |
