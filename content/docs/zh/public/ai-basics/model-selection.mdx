title: 模型选择方法
---

面对一堆模型名字不知道怎么选？这篇给你一个两分钟决策流程。

## 快速决策

```
你需要处理图片吗？
  ├── 是 → 选 gpt-4o
  └── 否 → 往下看
      你的任务复杂吗（长文、推理、复杂代码）？
        ├── 是 → 选 gpt-4 或 deepseek-chat
        └── 否 → 选 gpt-3.5-turbo（够用）
```

## 一句话版

- **日常聊天、简单问答、翻译** → `gpt-3.5-turbo`
- **写长文、深入分析、复杂编程** → `deepseek-chat`
- **数学、逻辑推理** → `deepseek-reasoner`
- **有图片要处理** → `gpt-4o`
- **不确定选哪个** → 先用 `gpt-3.5-turbo`，不够再升级

## 选模型时考虑什么

| 关注点 | 建议 |
|--------|------|
| 速度 | gpt-3.5-turbo 最快，deepseek-reasoner 最慢（要推理） |
| 质量 | gpt-4 > deepseek-chat > gpt-3.5-turbo |
| 成本 | gpt-3.5-turbo 最省，gpt-4 价格高很多 |
| 中文能力 | deepseek-chat 中文理解好 |
| 代码能力 | deepseek-chat 强，deepseek-reasoner 更强（但慢） |
| 上下文长度 | 需要处理长文档时选 gpt-4o（128K）或 deepseek-chat（64K） |

## 常见选型

### "我想写一个 Python 脚本处理 Excel"

→ 选 `gpt-3.5-turbo` 就行，任务不复杂

### "帮我分析这份 50 页的合同有什么风险"

→ 选 `gpt-4o`，上下文窗口大，理解能力强

### "帮我做一道数学证明题"

→ 选 `deepseek-reasoner`，它会一步步推理

### "我要做一个聊天机器人"

→ 日常对话用 `gpt-3.5-turbo`，需要高质量回复时用 `deepseek-chat`

## 不用纠结

同一个问题发给不同模型试试，对比了就知道了。模型列表和实时状态可在控制台查看。
