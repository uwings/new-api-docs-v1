## Short version

公益 API 服务免费提供 AI 模型调用能力，但有三条底线不可触碰：

1. **仅限合法用途**——不得用于违法、欺诈、侵害他人权益的场景。
2. **不得滥用资源**——禁止刷量、倒卖、超额并发、自动化爬取等消耗公共资源的行为。
3. **内容须合规**——不得生成或传播违法、色情、暴力、仇恨等违规内容。

违反以上任何一条，将按处置梯度执行，严重者永久封禁。

## 服务定位

公益 API 服务是面向合法授权场景的 AI API 网关与用量管理系统，以公益方式为开发者、学习者和研究团队提供 AI 模型调用能力。核心能力包括：

- 统一鉴权与多模型路由
- 用量统计与配额管理
- 公益配额发放与使用追踪
- 开发测试与学习研究支持

## 合法授权要求

用户在使用公益 API 服务时，必须满足以下要求：

- 合法取得使用资格，遵守注册与申请流程
- 遵守上游服务条款和平台规则
- 遵守所在地法律法规和监管要求
- 遵守适用的 AI 治理框架和内容安全要求

## 使用边界

使用公益 API 服务时，应确保相关场景合法授权、合规可审计，并符合以下要求：

- 遵守上游服务条款和平台规则
- 遵守所在地法律法规和监管要求
- 遵守内容安全、公共安全、网络安全和权益保护要求
- 遵守上游内容政策和适用的 AI 治理要求

## 公众服务义务

如用户面向不特定公众提供生成式 AI 服务，应自行完成所在地法律法规要求的合规义务，包括但不限于：

- 备案与资质要求
- 内容安全审核与治理机制
- 身份管理与日志留存
- 税务与支付合规
- 消费者保护
- 上游授权与服务条款遵循

<Callout type="warn">
  公益 API 服务默认面向个人学习、研究开发和合法合规场景。对外提供服务所涉及的合规义务，由使用者自行承担。
</Callout>

## 密钥与配额管理

- 用户应妥善保管个人 API Key，不得转让、共享或出售
- 配额仅限本人使用，不得用于商业转售或批量代理
- 多密钥管理、负载均衡等功能仅用于高可用和个人多场景管理
- 使用上述能力时，应遵守上游服务条款、平台规则和监管要求

## 内容安全

用户有义务确保通过公益 API 服务提供的内容符合安全要求。屏蔽词、日志记录、监控等功能应服务于内容安全和滥用治理。面向公众使用时应建立滥用举报、日志审计和处置机制。

## 禁止行为

以下行为明确禁止，一经发现将按处置梯度执行：

- 生成或传播违法、色情、暴力、仇恨、歧视性内容
- 滥用配额：刷量、超额并发、自动化爬取、循环调用
- 转售、倒卖 API Key 或配额，或将公益服务用于商业代理
- 利用服务进行欺诈、钓鱼、社工攻击或其他违法行为
- 绕过安全机制、限流策略或访问控制

## 处置梯度

对违反本政策的行为，管理团队将根据严重程度和违规次数，按以下梯度处置：

| 梯度 | 处置措施 | 适用情形 |
|------|---------|---------|
| 第一级 | 警告通知 | 首次轻微违规，以提醒纠正为主 |
| 第二级 | 限流降配 | 多次轻微违规或单次中度违规 |
| 第三级 | 临时封禁 3 天 | 中度违规或警告后未纠正 |
| 第四级 | 临时封禁 7 天 | 重复中度违规或单次较重违规 |
| 第五级 | 临时封禁 30 天 | 严重违规或多次中度违规 |
| 第六级 | 永久封禁 | 恶意违规、违法行为或严重影响服务 |

<Callout type="info">
  处置梯度为参考标准，实际执行可依据违规性质、影响范围和主观恶意程度调整。涉及违法行为将移交执法机关。
</Callout>

## 申诉入口

如对处置决定有异议，可通过以下方式申诉：

- **邮箱**：support@aididai.cn
- **预计响应时间**：3 个工作日内回复

申诉时请提供：账号信息、处置通知截图、申诉理由及相关证据。管理团队将重新审查并回复最终决定。
