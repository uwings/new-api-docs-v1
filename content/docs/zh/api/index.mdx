## 概述

aididai.cn 公益站提供完整的 AI 能力 API 接口，完全兼容 OpenAI API 格式，方便开发者无缝切换。所有接口通过 HTTPS 调用，使用 Bearer Token 鉴权。

<Callout title="基础信息">
  - **Base URL**：`https://aididai.cn/v1`
  - **鉴权方式**：在请求头中携带 `Authorization: Bearer sk-xxxxxxxx`
  - **联系邮箱**：support@aididai.cn
  - **API Key 获取**：登录公益站后在控制台创建令牌即可获得
</Callout>

## 快速开始

以下是一个最简单的调用示例，使用 Chat Completions 接口与模型对话：

```bash
curl https://aididai.cn/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "user", "content": "你好，请介绍一下你自己"}
    ]
  }'
```

<Callout type="warn" title="注意事项">
  - 请妥善保管你的 API Key，不要泄露给他人。
  - 公益站资源有限，请合理使用，避免高频大并发请求。
  - 所有接口均兼容 OpenAI API 格式，可直接使用 OpenAI SDK、LangChain 等工具库。
</Callout>
