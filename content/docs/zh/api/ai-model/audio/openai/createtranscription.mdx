## 概述

将音频文件转录为文本（Speech to Text）。支持多种音频格式，兼容 OpenAI Whisper API。

**接口地址**：`POST https://aididai.cn/v1/audio/transcriptions`

## 请求参数

请求使用 `multipart/form-data` 格式。

### 必需参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `file` | file | 要转录的音频文件。支持格式：`mp3`、`mp4`、`mpeg`、`mpga`、`m4a`、`wav`、`webm`、`ogg`。文件大小不超过 25 MB。 |
| `model` | string | 转录模型，推荐使用 `whisper-1`。 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `language` | string | — | 音频语言，ISO 639-1 格式（如 `zh`）。不指定则由模型自动检测。 |
| `response_format` | string | `json` | 输出格式：`json`、`text`、`srt`、`verbose_json`、`vtt`。 |
| `temperature` | number | 0 | 采样温度，0-1 之间。值越高输出越随机。 |
| `prompt` | string | — | 引导词，提供上下文或词汇提示以提升识别准确率。 |

## 请求示例

### cURL 示例

```bash
curl https://aididai.cn/v1/audio/transcriptions \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -F "file=@audio.mp3" \
  -F "model=whisper-1" \
  -F "language=zh" \
  -F "response_format=json"
```

### Python 示例

```python
import requests

url = "https://aididai.cn/v1/audio/transcriptions"
headers = {"Authorization": "Bearer sk-xxxxxxxx"}

with open("audio.mp3", "rb") as audio_file:
    files = {"file": ("audio.mp3", audio_file, "audio/mpeg")}
    data = {
        "model": "whisper-1",
        "language": "zh"
    }
    response = requests.post(url, headers=headers, files=files, data=data)
    print(response.json())
```

### 使用 OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://aididai.cn/v1",
    api_key="sk-xxxxxxxx"
)

with open("audio.mp3", "rb") as audio_file:
    transcription = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="zh"
    )

print(transcription.text)
```

## 响应示例

### JSON 格式

```json
{
  "text": "你好，欢迎使用 aididai 公益站。我们提供多种 AI 模型接口。"
}
```

### verbose_json 格式

```json
{
  "task": "transcribe",
  "language": "chinese",
  "duration": 5.2,
  "text": "你好，欢迎使用 aididai 公益站。",
  "segments": [
    {
      "id": 0,
      "start": 0.0,
      "end": 2.5,
      "text": "你好，欢迎使用",
      "tokens": [50364, 12345, ...]
    },
    {
      "id": 1,
      "start": 2.5,
      "end": 5.2,
      "text": "aididai 公益站。",
      "tokens": [50364, 67890, ...]
    }
  ]
}
```

### SRT / VTT 字幕格式

设置 `response_format=srt` 返回带时间戳的字幕格式，可直接用于视频字幕：

```
1
00:00:00,000 --> 00:00:02,500
你好，欢迎使用

2
00:00:02,500 --> 00:00:05,200
aididai 公益站。
```

  - 音频质量越高（采样率、信噪比），识别效果越好。
</Callout>
