## 概述

将文本转换为自然语音的音频文件。支持多种音色和输出格式，兼容 OpenAI Text-to-Speech API。

**接口地址**：`POST https://airider.cn/v1/audio/speech`

## 请求参数

### 必需参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | string | TTS 模型 ID，如 `tts-1`（标准质量，延迟低）、`tts-1-hd`（高音质，延迟稍高）。 |
| `input` | string | 要合成语音的文本内容，最多 4096 字符。 |
| `voice` | string | 语音音色：`alloy`、`echo`、`fable`、`onyx`、`nova`、`shimmer`。 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `response_format` | string | `mp3` | 输出音频格式：`mp3`、`opus`、`aac`、`flac`、`wav`、`pcm`。 |
| `speed` | number | 1.0 | 语速，范围 0.25 到 4.0。1.0 为正常语速。 |

## 请求示例

### cURL 示例

```bash
curl https://airider.cn/v1/audio/speech \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{
    "model": "tts-1",
    "input": "你好，欢迎使用 aididai 公益站。我们提供多种 AI 模型接口，完全免费。",
    "voice": "alloy",
    "speed": 1.0
  }' \
  --output speech.mp3
```

### Python 示例

```python
import requests

url = "https://airider.cn/v1/audio/speech"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer sk-xxxxxxxx"
}
data = {
    "model": "tts-1",
    "input": "你好，欢迎使用 aididai 公益站。",
    "voice": "alloy"
}

response = requests.post(url, json=data, headers=headers)

# 保存音频文件
with open("speech.mp3", "wb") as f:
    f.write(response.content)
print("音频已保存为 speech.mp3")
```

### 使用 OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://airider.cn/v1",
    api_key="sk-xxxxxxxx"
)

response = client.audio.speech.create(
    model="tts-1",
    voice="alloy",
    input="你好，欢迎使用 aididai 公益站。"
)

response.stream_to_file("speech.mp3")
```

## 响应

成功时返回音频二进制数据（`Content-Type: audio/mpeg` 等），可直接保存为文件或流式播放。

<Callout type="info" title="音色说明">
  | 音色 | 描述 |
  |------|------|
  | `alloy` | 中性、专业，适合大多数场景 |
  | `echo` | 深沉、有共鸣 |
  | `fable` | 温暖、叙述风格，适合讲故事 |
  | `onyx` | 深沉有力，适合正式场景 |
  | `nova` | 温柔、女性化 |
  | `shimmer` | 轻快、清晰 |
</Callout>

<Callout type="warn" title="注意事项">
  - 文本长度上限为 4096 字符，超过需要分段合成。
  - TTS 模型的可用性可能受公益站资源限制，建议通过模型列表接口确认。
</Callout>
