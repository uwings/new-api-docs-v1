## 概述

实时语音接口通过 WebSocket 协议建立双向低延迟音频通道，支持实时语音对话、语音指令等场景。与普通的 REST API 不同，该接口使用 WebSocket 协议进行通信。

<Callout type="warn" title="WebSocket 协议">
  这不是一个普通的 HTTP 请求接口。你需要使用 WebSocket 客户端建立连接：

  ```
  wss://airider.cn/v1/realtime?model=gpt-4o-realtime
  ```

  连接时需要携带认证信息（通常通过 URL 参数或连接头）。
</Callout>

<Callout title="可用性说明">
  实时语音接口需要支持音频的特定模型，且在公益站上的可用性受限于服务器资源。建议通过模型列表接口确认当前可用的实时语音模型。
</Callout>
