## 概述

Responses API 是 OpenAI 推荐的新一代对话接口，相比 Chat Completions 提供了更丰富的功能，包括内置工具调用、结构化输出等。

**接口地址**：`POST https://airider.cn/v1/responses`

<Callout title="说明">
  Responses API 是较新的接口格式，部分模型可能尚未完整支持。如遇兼容问题，建议使用 Chat Completions 接口作为降级方案。
</Callout>

## 请求参数

### 必需参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | string | 使用的模型 ID，如 `gpt-4o`、`gpt-4o-mini` 等。 |
| `input` | string \| array | 用户输入，可以是纯文本字符串或消息数组。 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `instructions` | string | — | 系统级别的指令，定义助手的行为和角色。 |
| `max_output_tokens` | integer | — | 最大输出 token 数。 |
| `temperature` | number | 1 | 采样温度，0-2 之间。 |
| `top_p` | number | 1 | 核采样参数。 |
| `stream` | boolean | false | 是否启用流式输出。 |
| `tools` | array | — | 内置工具列表，如 web_search、file_search 等。 |
| `tool_choice` | string \| object | — | 工具调用控制。 |
| `reasoning` | object | — | 推理强度配置，`{"effort": "medium"}` 可控制推理深度。 |
| `previous_response_id` | string | — | 上一轮响应的 ID，用于多轮对话上下文关联。 |

## 请求示例

### cURL 示例

```bash
curl https://airider.cn/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{
    "model": "gpt-4o-mini",
    "instructions": "你是一个知识渊博的助手。",
    "input": "介绍一下量子计算的基本原理",
    "temperature": 0.7,
    "max_output_tokens": 300
  }'
```

### Python 示例

```python
import requests

url = "https://airider.cn/v1/responses"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer sk-xxxxxxxx"
}
data = {
    "model": "gpt-4o-mini",
    "instructions": "你是一个知识渊博的助手。",
    "input": "介绍一下量子计算的基本原理",
    "temperature": 0.7,
    "max_output_tokens": 300
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```

### 非流式响应

```json
{
  "id": "resp_abc123def456",
  "object": "response",
  "created_at": 1710000000,
  "status": "completed",
  "model": "gpt-4o-mini",
  "output": [
    {
      "type": "message",
      "id": "msg_001",
      "role": "assistant",
      "content": [
        {
          "type": "output_text",
          "text": "量子计算利用量子比特（qubit）的叠加态和纠缠态进行计算..."
        }
      ]
    }
  ],
  "usage": {
    "input_tokens": 20,
    "output_tokens": 150,
    "total_tokens": 170
  }
}
```

### 流式响应

设置 `"stream": true` 后，服务器将以 SSE 格式返回增量更新：

```
event: response.created
data: {"type": "response.created", "response": {"id": "resp_001", "status": "in_progress", ...}}

event: response.output_text.delta
data: {"type": "response.output_text.delta", "delta": "量子", ...}

event: response.output_text.delta
data: {"type": "response.output_text.delta", "delta": "计算", ...}

event: response.completed
data: {"type": "response.completed", "response": {"id": "resp_001", "status": "completed", ...}}
```

<Callout type="info" title="与 Chat Completions 的区别">
  - **输入方式**：Responses 使用 `input` 字段而非 `messages` 数组。
  - **上下文管理**：支持通过 `previous_response_id` 传递上下文，无需在客户端维护消息历史。
  - **内置工具**：支持直接配置 `tools` 字段调用内置工具（如网络搜索、文件检索）。
</Callout>

<Callout type="warn" title="注意事项">
  部分模型对 Responses API 的支持可能不完整。如遇到错误或不支持的参数，请改用 Chat Completions 接口。
</Callout>
