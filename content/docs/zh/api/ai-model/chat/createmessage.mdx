## 概述

Claude Messages 接口兼容 Anthropic 原生 Messages API 格式，可直接使用 Anthropic SDK 调用。支持 Claude 系列模型。

**接口地址**：`POST https://airider.cn/v1/messages`

<Callout title="兼容性">
  该接口兼容 Anthropic Messages API。可直接使用 `anthropic` Python SDK，只需将 `base_url` 修改为 `https://airider.cn/v1`。
</Callout>

## 请求头

| 请求头 | 说明 |
|------|------|
| `x-api-key` | API Key，值为 `sk-xxxxxxxx` |
| `anthropic-version` | API 版本，如 `2023-06-01` |
| `content-type` | `application/json` |

## 请求参数

### 必需参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | string | 模型 ID，如 `claude-3.5-sonnet`、`claude-3-opus`、`claude-3-haiku`。 |
| `messages` | array | 对话消息列表。每条消息含 `role`（`user` / `assistant`）和 `content`（字符串或内容块数组）。 |
| `max_tokens` | integer | 生成的最大 token 数（Claude 接口必需）。 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `system` | string \| array | — | 系统提示，定义助手行为和角色。 |
| `temperature` | number | 1 | 采样温度，0-1 之间。 |
| `top_p` | number | — | 核采样参数。 |
| `top_k` | integer | — | Top-K 采样，只从概率最高的 K 个 token 中选择。 |
| `stream` | boolean | false | 是否启用流式输出。 |
| `stop_sequences` | array | — | 自定义停止序列。 |
| `tools` | array | — | 工具定义列表，支持 Function Calling。 |
| `tool_choice` | object | — | 工具调用控制。 |

## 请求示例

### cURL 示例

```bash
curl https://airider.cn/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: sk-xxxxxxxx" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-3.5-sonnet",
    "system": "你是一个乐于助人的助手。",
    "messages": [
      {"role": "user", "content": "请用一句话介绍杭州西湖。"}
    ],
    "max_tokens": 200,
    "temperature": 0.7
  }'
```

### Python 示例

```python
import requests

url = "https://airider.cn/v1/messages"
headers = {
    "Content-Type": "application/json",
    "x-api-key": "sk-xxxxxxxx",
    "anthropic-version": "2023-06-01"
}
data = {
    "model": "claude-3.5-sonnet",
    "system": "你是一个乐于助人的助手。",
    "messages": [
        {"role": "user", "content": "请用一句话介绍杭州西湖。"}
    ],
    "max_tokens": 200
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```

### 使用 Anthropic SDK

```python
from anthropic import Anthropic

client = Anthropic(
    base_url="https://airider.cn/v1",
    api_key="sk-xxxxxxxx"
)

response = client.messages.create(
    model="claude-3.5-sonnet",
    system="你是一个乐于助人的助手。",
    messages=[
        {"role": "user", "content": "你好！"}
    ],
    max_tokens=200
)

print(response.content[0].text)
```

<Callout type="warn" title="注意事项">
  - `max_tokens` 是必填参数，与 OpenAI 接口不同。
  - 需要同时设置 `x-api-key` 和 `anthropic-version` 请求头。
  - 不同版本的 Claude 模型支持的参数可能不同。
</Callout>
