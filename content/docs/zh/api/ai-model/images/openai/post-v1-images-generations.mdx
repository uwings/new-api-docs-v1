在给定文字描述（prompt）的情况下生成图像。支持 DALL-E 系列模型。

## 接口地址

```
POST https://aididai.cn/v1/images/generations
```

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | ✅ | 模型 ID，如 `dall-e-3` |
| `prompt` | string | ✅ | 图像描述，最长 4000 字符 |
| `n` | integer | ❌ | 生成图像数量，1-10，默认 1 |
| `size` | string | ❌ | 图像尺寸，如 `1024x1024`、`1792x1024` |
| `response_format` | string | ❌ | 返回格式，`url`（默认）或 `b64_json` |
| `quality` | string | ❌ | 图像质量，`standard`（默认）或 `hd` |
| `style` | string | ❌ | 图像风格，`vivid`（默认）或 `natural` |

## 请求示例

### cURL

```bash
curl https://aididai.cn/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{
    "model": "dall-e-3",
    "prompt": "一只戴着墨镜的橘猫正在用笔记本电脑写代码，数字艺术风格",
    "n": 1,
    "size": "1024x1024",
    "quality": "standard"
  }'
```

### Python

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",
    base_url="https://aididai.cn/v1"
)

response = client.images.generate(
    model="dall-e-3",
    prompt="一只戴着墨镜的橘猫正在用笔记本电脑写代码，数字艺术风格",
    n=1,
    size="1024x1024"
)
print(response.data[0].url)
```

## 响应示例

```json
{
  "created": 1750000000,
  "data": [
    {
      "url": "https://cdn.aididai.cn/images/gen_xxxxx.png",
      "revised_prompt": "一只戴着墨镜的橘猫坐在桌前，正在使用笔记本电脑..."
    }
  ]
}
```

<Callout type="warn" title="注意">
  图像生成消耗的 Token 额度远高于文本对话，请合理使用。
  生成的图像 URL 可能有有效期限制，请及时下载保存。
</Callout>
