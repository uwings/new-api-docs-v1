获取当前公益站可用的模型列表。

## 接口地址

```
GET https://aididai.cn/v1/models
```

## 请求方式

```bash
curl https://aididai.cn/v1/models \
  -H "Authorization: Bearer sk-xxxxxxxx"
```

### Python

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",
    base_url="https://aididai.cn/v1"
)

models = client.models.list()
for m in models.data:
    print(m.id)
```

## 多格式支持

通过设置不同的请求头，可以获取其他格式的模型列表：

| 格式 | 请求头 |
|------|--------|
| OpenAI | 默认格式，无需特殊头 |
| Anthropic | `x-api-key: sk-xxx` + `anthropic-version: 2023-06-01` |
| Gemini | `x-goog-api-key: sk-xxx` 或 `?key=sk-xxx` |

<Callout type="info">
  模型列表可能随平台策略动态调整。返回的模型不一定全部可用——部分模型可能受额度或权限限制。
</Callout>
