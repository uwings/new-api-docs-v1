## 概述

Moderations 接口检查文本是否包含违规内容，如仇恨言论、暴力、色情、自残等内容类别。兼容 OpenAI Moderations API。

**接口地址**：`POST https://airider.cn/v1/moderations`

## 请求参数

### 必需参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `input` | string \| array | 需要审查的文本。可以是单个字符串或字符串数组。 |
| `model` | string | 审查模型，如 `omni-moderation-latest`、`text-moderation-stable`。 |

## 请求示例

### cURL 示例

```bash
curl https://airider.cn/v1/moderations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{
    "model": "omni-moderation-latest",
    "input": "你好，今天天气怎么样？"
  }'
```

### Python 示例

```python
import requests

url = "https://airider.cn/v1/moderations"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer sk-xxxxxxxx"
}
data = {
    "model": "omni-moderation-latest",
    "input": "你好，今天天气怎么样？"
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```

### 使用 OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://airider.cn/v1",
    api_key="sk-xxxxxxxx"
)

response = client.moderations.create(
    model="omni-moderation-latest",
    input="你好，今天天气怎么样？"
)

print(response.results[0])
```

### 响应字段说明

| 字段 | 说明 |
|------|------|
| `flagged` | 是否被标记为违规内容。`true` 表示可能包含违规内容。 |
| `categories` | 各内容类别是否被触发。 |
| `category_scores` | 各内容类别的置信度分数（0-1），越接近 1 表示违规概率越高。 |
