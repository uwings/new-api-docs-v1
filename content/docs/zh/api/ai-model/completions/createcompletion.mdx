## 概述

Completions 是传统的文本补全接口，给定一段文本前缀，模型续写后续内容。这是 OpenAI 早期的核心接口，适用于纯文本续写、代码生成等无对话上下文的场景。

**接口地址**：`POST https://airider.cn/v1/completions`

## 请求参数

### 必需参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | string | 使用的模型 ID，如 `gpt-3.5-turbo-instruct`。注意：大部分 Chat 模型也兼容此接口。 |
| `prompt` | string \| array | 提示文本。可以是单个字符串或字符串数组。 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `max_tokens` | integer | 16 | 生成的最大 token 数。 |
| `temperature` | number | 1 | 采样温度，0-2 之间。 |
| `top_p` | number | 1 | 核采样参数。 |
| `stream` | boolean | false | 是否启用流式输出。 |
| `stop` | string \| array | — | 停止序列，遇到时停止生成。 |
| `n` | integer | 1 | 生成的补全数量。 |
| `suffix` | string | — | 插入文本后的后缀（代码补全场景常用）。 |
| `echo` | boolean | false | 是否在响应中回显 prompt。 |

## 请求示例

### cURL 示例

```bash
curl https://airider.cn/v1/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{
    "model": "gpt-3.5-turbo-instruct",
    "prompt": "人工智能是",
    "max_tokens": 100,
    "temperature": 0.7,
    "stop": ["。", "\n\n"]
  }'
```

### Python 示例

```python
import requests

url = "https://airider.cn/v1/completions"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer sk-xxxxxxxx"
}
data = {
    "model": "gpt-3.5-turbo-instruct",
    "prompt": "人工智能是",
    "max_tokens": 100,
    "temperature": 0.7
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```

<Callout type="info" title="何时用 Completions 而非 Chat Completions？">
  对于大多数对话场景，推荐使用 [Chat Completions](/zh/docs/api/ai-model/chat/openai/createchatcompletion) 接口。Completions 接口更适合纯文本续写、代码补全、故事生成等不需要消息结构体的场景。
