## 概述

Rerank 接口根据查询（query）对一组文档进行语义相关性排序。常用于 RAG（检索增强生成）场景中，对初步检索到的文档进行精排，提升最终结果的相关性。

**接口地址**：`POST https://airider.cn/v1/rerank`

## 请求参数

### 必需参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | string | 重排序模型 ID，如 `bge-reranker-v2-m3`、`jina-reranker-v2`。 |
| `query` | string | 查询文本，用于评估文档相关性。 |
| `documents` | array | 待排序的文档列表，每个元素为字符串。 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `top_n` | integer | — | 只返回相关性最高的 top_n 条文档。不指定则返回全部文档并按相关性排序。 |
| `return_documents` | boolean | true | 是否在响应中返回文档原文。设为 `false` 可减小响应体积。 |

### Python 示例

```python
import requests

url = "https://airider.cn/v1/rerank"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer sk-xxxxxxxx"
}
data = {
    "model": "bge-reranker-v2-m3",
    "query": "人工智能在医疗领域的应用",
    "documents": [
        "量子计算是计算机科学的一个前沿领域...",
        "AI 在医学影像诊断中表现出了极高的准确率...",
        "深度学习帮助医生更早地发现肿瘤..."
    ],
    "top_n": 2
}

response = requests.post(url, json=data, headers=headers)
result = response.json()

for item in result["results"]:
    print(f"排名 {item['index']}: 相关性={item['relevance_score']:.4f}")
```

## 典型 RAG 流程

```python
# 1. 向量检索：从知识库中召回候选文档
from openai import OpenAI
client = OpenAI(base_url="https://airider.cn/v1", api_key="sk-xxxxxxxx")

query_embedding = client.embeddings.create(
    model="text-embedding-3-small",
    input="人工智能在医疗领域的应用"
).data[0].embedding

# 在向量数据库中搜索相似文档（此处省略检索逻辑）
candidates = vector_search(query_embedding, top_k=20)

# 2. 重排序：用 Rerank 接口精排
import requests
rerank_response = requests.post(
    "https://airider.cn/v1/rerank",
    headers={"Authorization": "Bearer sk-xxxxxxxx"},
    json={
        "model": "bge-reranker-v2-m3",
        "query": "人工智能在医疗领域的应用",
        "documents": [doc["text"] for doc in candidates],
        "top_n": 5
    }
)

top_docs = rerank_response.json()["results"]
```

<Callout type="warn" title="注意事项">
  - 文档数量不宜过多，一般建议在 20-50 条以内以保证响应速度。
  - 不同重排序模型有各自的打分尺度，分数不应跨模型比较。
  - 公益站可能根据负载限制单次请求的文档数量和调用频率。
</Callout>
