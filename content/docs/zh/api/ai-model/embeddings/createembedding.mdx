## 概述

Embeddings 接口将文本转换为高维向量，用于语义搜索、文本聚类、推荐系统等场景。生成的向量可以用于计算文本之间的语义相似度。

**接口地址**：`POST https://aididai.cn/v1/embeddings`

## 请求参数

### 必需参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | string | 嵌入模型 ID，如 `text-embedding-3-small`、`text-embedding-3-large`、`text-embedding-ada-002`。 |
| `input` | string \| array | 需要嵌入的文本。可以是单个字符串或字符串数组（批量最多 2048 条）。 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `encoding_format` | string | `float` | 返回格式：`float`（浮点数数组）或 `base64`（Base64 编码）。 |
| `dimensions` | integer | — | 输出的向量维度。仅 `text-embedding-3` 系列模型支持缩短维度。如设为 256 时只返回前 256 维。 |
| `user` | string | — | 终端用户标识，用于监控和滥用检测。 |

## 请求示例

### cURL 示例（单条文本）

```bash
curl https://aididai.cn/v1/embeddings \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{
    "model": "text-embedding-3-small",
    "input": "人工智能正在改变世界",
    "encoding_format": "float"
  }'
```

### cURL 示例（批量文本）

```bash
curl https://aididai.cn/v1/embeddings \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{
    "model": "text-embedding-3-small",
    "input": [
      "人工智能正在改变世界",
      "机器学习是人工智能的一个分支",
      "深度学习使用神经网络"
    ]
  }'
```

### Python 示例

```python
import requests

url = "https://aididai.cn/v1/embeddings"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer sk-xxxxxxxx"
}
data = {
    "model": "text-embedding-3-small",
    "input": "人工智能正在改变世界"
}

response = requests.post(url, json=data, headers=headers)
result = response.json()
embedding = result["data"][0]["embedding"]
print(f"向量维度: {len(embedding)}")
print(f"前5个值: {embedding[:5]}")
```

### 使用 OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://aididai.cn/v1",
    api_key="sk-xxxxxxxx"
)

response = client.embeddings.create(
    model="text-embedding-3-small",
    input="人工智能正在改变世界",
    dimensions=256
)

print(response.data[0].embedding)
```

<Callout type="info" title="向量模型选择">
  - `text-embedding-3-small`：性价比最高的选择，512 维默认，适合大多数场景。
  - `text-embedding-3-large`：更高精度，3072 维默认，适合对准确度要求高的场景。
  - 两个模型都支持 `dimensions` 参数缩短向量维度以节省存储和计算成本。
</Callout>
