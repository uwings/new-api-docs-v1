## 概述

查询已提交的视频生成任务的当前状态和结果。

**接口地址**：`GET https://aididai.cn/v1/videos/{video_id}`

### 任务状态说明

| 状态 | 说明 |
|------|------|
| `queued` | 排队等待处理 |
| `in_progress` | 正在生成中 |
| `completed` | 生成成功，结果可用 |
| `failed` | 生成失败 |

<Callout type="info">
  视频生成通常是异步的，提交任务后需要轮询此接口直到状态变为 `completed`。
</Callout>
