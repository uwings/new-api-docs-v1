## 概述

使用 Kling 模型从参考图片生成视频。可传入图片 URL 或 Base64 编码的图片数据。

**接口地址**：`POST https://aididai.cn/v1/videos`

<Callout type="info">
  也支持 [文生视频](/zh/docs/api/ai-model/videos/kling/createklingtext2video) 模式。
