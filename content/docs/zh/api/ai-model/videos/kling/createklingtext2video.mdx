## 概述

使用 Kling 模型从文本描述生成视频。

**接口地址**：`POST https://aididai.cn/v1/videos`

<Callout type="info">
  Kling 视频生成是异步的。提交任务后可通过 [获取状态接口](/zh/docs/api/ai-model/videos/kling/getklingtext2video) 查询进度。也支持 [图生视频](/zh/docs/api/ai-model/videos/kling/createklingimage2video) 模式。
</Callout>
