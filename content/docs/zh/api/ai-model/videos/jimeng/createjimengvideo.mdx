## 概述

使用即梦（Jimeng）官方 API 格式进行视频生成，通过 `Action` 参数区分提交任务和获取结果。

**接口地址**：`POST https://airider.cn/v1/videos`

### Action 参数

| 值 | 说明 |
|------|------|
| `CVSync2AsyncSubmitTask` | 提交视频生成任务 |
| `CVSync2AsyncGetResult` | 获取任务结果 |

<Callout type="info">
  即梦接口使用火山引擎格式，与 OpenAI 格式不同。具体请求体结构请参考即梦官方文档。
</Callout>
