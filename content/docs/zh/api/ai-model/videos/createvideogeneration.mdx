## 概述

提交 AI 视频生成任务。该接口兼容 OpenAI 视频生成 API 格式，底层支持 Sora、Kling、即梦等多种视频模型。

**接口地址**：`POST https://airider.cn/v1/videos`

<Callout type="warn">
  视频生成消耗大量 GPU 资源，公益站可能对此类请求有额外的频率限制。生成的视频文件可能设有有效期，请及时下载保存。
</Callout>

<Callout type="info" title="子格式">
  不同视频模型的子格式和参数有差异，请参考具体子页面：
  - [Sora 格式](/zh/docs/api/ai-model/videos/sora/createvideo)
  - [Kling 格式](/zh/docs/api/ai-model/videos/kling/createklingtext2video)
  - [即梦格式](/zh/docs/api/ai-model/videos/jimeng/createjimengvideo)
</Callout>
